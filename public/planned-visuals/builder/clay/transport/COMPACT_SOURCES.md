# Transport Bar — illustrations compactes

Cinq PNG RGBA décoratifs créés avec l’outil intégré imagegen (`transparent_background=true`). Aucun ancien fichier n’est remplacé. Alpha vérifié : minimum 0, maximum 255 sur chaque fichier. Utilisation limitée à BarProductVisual, côté ouvert/dock ; affichage `contain` centré.

- car-compact.png : voiture compacte crème/lavande, entière, vue trois quarts.
- bus-compact.png : bus urbain crème/lavande, entier, vue trois quarts.
- train-compact.png : train de banlieue crème/lavande, entier, vue trois quarts.
- walking-compact.png : paire de chaussures de marche crème/lavande, entière.
- taxi-compact.png : petit taxi jaune, entier, vue trois quarts.

Prompt commun : une seule illustration UI 3D Clay douce, arrondie, lisible à 48 pixels ; objet centré avec marges transparentes, sans décor, sol ni fond. Taxi : aucun halo, seulement la silhouette avec alpha nul à l’extérieur. Ni prix, ni modèle de véhicule, ni décision utilisateur ne sont déduits de ces images.

Boissons conserve `r7/family-drinks.webp` ; Restauration/Nourriture sur place réutilisent `bar-compact/tapas.webp`. Les consommations déjà détourées restent inchangées.
