# Global Analytics Dependency Matrix — GA0

## Objet et règles de lecture

Cette matrice est la vue physique post-History des sorties Global. Elle ne transforme ni les ReadModels History ni une valeur d'oracle en intrant de production. Les dépendances `history_*` citées ci-dessous désignent les autorités amont (Facts, Analytics officiels, artifacts certifiés et leurs hashes), jamais une concaténation de payloads History.

Abréviations : `ECF` = `EconomicComponentFact`, `AOF` = `ActivityOccurrenceFact`, `AOCF` = `ActivityOccurrenceCostFact`, `PDF` = `PersonDayFact`, `PEF` = `PurchaseEventFact`, `PVF` = `PlaceVisitFact`, `CR` = `CanonicalRepository`, `FSR` = `FactSourceResolver`. `CH` signifie `CERTIFIED_HISTORY`; `LT` signifie `LIVE_TAIL`.

Les identifiants de décision (`H*`, `F*`, `M*`) renvoient au registre de classification de `GA0-post-history-reality-check.md`. Une ligne peut référencer plusieurs décisions, mais chaque pièce structurelle n'a qu'une classification dans ce registre.

## Invariants de fermeture

- Chaque dépendance de fait doit entrer dans `resourceInputHash` ou être relue par le manifest; le manifest Global doit exposer `manifestHash`, `publicationFactsHash`, versions, lookbacks et lineage.
- Les artifacts History peuvent être des dépendances certifiées identifiées par hash/génération. Ils ne sont pas des ReadModels Global et ne sont jamais concaténés côté Query ou React.
- Un changement LT peut rafraîchir une sortie descriptive explicitement LT; il ne peut seul changer un change point, un régime, une phase ou une conclusion certifiée.
- Les trous, les supports non comparables et les attributions inconnues restent visibles. Aucun zéro, partage 50/50, route, achat, routine ou causalité n'est inventé.
- Le profil Global doit être snapshot-only et fail-closed avant cutover; le read-through actuel des ressources `analysis_global_*` n'est pas conservé.
