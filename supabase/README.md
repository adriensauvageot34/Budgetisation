# Supabase V2 distante

La base distante est déjà migrée, alimentée et validée en V2. Elle ne doit jamais
être réinitialisée automatiquement et les anciens scripts V1 ne doivent jamais
être exécutés.

Toute future évolution SQL doit prendre la forme d’une migration V2 explicite,
ciblée et relue. Les données personnelles et financières réelles ne doivent
jamais être stockées dans ce dépôt.
